# E-Commerce Revenue Analytics Dashboard(Interactive Dashboard Create using PowrBI)
## Project Objective
This Power BI project analyzes e-commerce sales data to track revenue performance, customer purchasing trends, and business KPIs.

## Process
Revenue Performance Monitoring
Average Order Value (AOV) Analysis
Lost Revenue from Order Cancellations
Cancellation Rate Tracking
Product-wise Revenue Analysis
Category-wise Sales Analysis
State-wise Revenue Distribution
Revenue Trend Analysis
Interactive Date and Category Filters

## Tools Used
Power BI Desktop
DAX Measures
Data Modeling
Interactive Visualizations

## Business Insights
Identify top-performing products and categories.
Track revenue growth trends over time.
Monitor cancellation-related revenue loss.
Analyze regional sales performance.
Support strategic business decision-making through data visualization.
